# 온보딩 문서 자동화

신규 팀원을 위한 온보딩 문서를 Claude로 자동 생성합니다.

## 온보딩 체크리스트

```markdown
# 신규 입사자 온보딩

## 1주차
- [ ] 개발 환경 세팅
- [ ] Vault 접근 권한
- [ ] 주요 프로젝트 개요

## 2주차
- [ ] 코드베이스 투어
- [ ] 아키텍처 설명
- [ ] 첫 태스크
```

## Claude로 자동 생성

```markdown
Claude:
"프로젝트 {{이름}}의
온보딩 문서를 만들어줘.

포함할 내용:
1. 프로젝트 개요
2. 아키텍처
3. 개발 환경 세팅
4. 주요 연락처
5. 자주 묻는 질문"

기존 노트들을 분석해서 생성해줘.
```

## 자동화된 내용

```markdown
---
title: "{{팀}} 온보딩 가이드"
tags: [onboarding, {{team}}]
---

# {{팀}} 온보딩 가이드

## 팀 소개
{{팀 내용}}

## 프로젝트 구조
{{프로젝트}}

## 개발 환경
{{세팅}}

## 첫 주 계획
{{일정}}

## FAQ
{{자주 묻는 질문}}
```

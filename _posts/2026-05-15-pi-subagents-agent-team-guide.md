    15|> **TL;DR** — Pi 코딩 에이전트의 서브에이전트 기능을 설치부터 실전 활용까지 정리. scout, planner, worker, reviewer 등 8개 전문 에이전트를 자연어로 지시하고, 병렬 실행으로 코딩 생산성을 극적으로 높이는 방법.
    16|
    17|---
    18|
    19|**Pi**는 터미널에서 작동하는 오픈소스 AI 코딩 에이전트다 (Mario Zechner 제작, npm 기반). 이 글에서 다루는 **서브에이전트**는 Pi가 작업을 전문가 역할의 자식 에이전트에게 나눠서 맡기는 기능이다. 마치 팀장이 각 팀원에게 맞는 역할을 분배하는 것과 같다.
    20|
    21|Pi를 쓰면서 서브에이전트 기능을 안 써봤다면 잠재력의 10%도 쓰지 않은 거다.
    22|
    23|> **Before:** Pi에게 "코드 파악→계획→구현→리뷰"를 하나씩 순서대로 지시. 한 명이 다 하는 거라 느리고 컨텍스트도 낭비됨.
    24|>
    25|> **After:** `scout`가 파악 → `planner`가 계획 → `worker`가 구현 → `reviewer`가 리뷰. 각자 전문 모델+전문 도구로 동시에 작업.
    26|
    27|이 글에서는 설치부터 실전 패턴까지, 한국어로 지시하는 방법을 중심으로 정리한다.
    28|
    29|## 패키지 설치
    30|
    31|Pi에 서브에이전트 기능은 별도 패키지로 제공된다.
    32|
    33|```bash
    34|# 공식 pi-subagents (권장)
    35|pi install npm:pi-subagents
    36|```
    37|
    38|Claude Code 스타일을 선호하면 대안도 있다:
    39|
    40|```bash
    41|pi install npm:@tintinweb/pi-subagents
    42|```
    43|
    44|## 5분 시작하기
    45|
    46|설치 후 바로 체험해볼 수 있다. 프로젝트 디렉토리에서 Pi를 실행하고:
    47|
    48|```
    49|scout로 이 프로젝트 구조를 파악해줘
    50|```
